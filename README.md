# ECOM6003 Portfolio Data Preparation

This repository contains the R code used to support **Section 2.1: Data Collection and Stock Selection** of the ECOM6003 portfolio project.

## Project purpose

The project develops an investment strategy for a medium-risk client investing **$10 million in S&P 500 companies over a five-year investment horizon**.

This repository focuses only on the data collection and preparation work for the 15 candidate stocks. It does not reproduce the ARIMA modelling, variance-covariance modelling, portfolio optimisation, VaR analysis, or out-of-sample backtesting completed in other sections of the group project.

## Data period

The R script retrieves Yahoo Finance data for the **in-sample period from January 2020 to December 2024**.

The wider project uses:

- **In-sample:** January 2020–December 2024
- **Out-of-sample:** January 2025–December 2025

Only the in-sample preparation is reproduced in this repository.

## What the R script does

`R/01_data_collection.R`:

1. Downloads Yahoo Finance market data using `quantmod::getSymbols()`.
2. Extracts adjusted closing prices.
3. Aligns common trading dates across all 15 stocks.
4. Checks missing observations.
5. Calculates data completeness across the retained common trading dates.
6. Calculates discrete daily returns.
7. Exports reproducible summary datasets to the `output/` folder.

## How to run

Open RStudio and set the working directory to this repository, then run:

```r
source("R/01_data_collection.R")
```

If the required packages are not installed, first run:

```r
install.packages(c("quantmod", "dplyr", "tibble", "xts"))
```

## Expected report checks

The final report currently states that the aligned dataset contains:

- 1,258 daily adjusted-price observations per selected stock
- 1,257 aligned daily return observations
- 100% completeness across the common trading dates retained in the final aligned dataset

**Important:** check these values against the output from your actual R run. Market-data providers can revise historical records, so the report should use the values generated by the reproducible code rather than forcing a particular result.

## Output files

After running the script, the following files are created:

- `output/data_completeness.csv`
- `output/aligned_adjusted_prices_2020_2024.csv`
- `output/aligned_daily_returns_2020_2024.csv`

## Data source

Historical market data are retrieved from Yahoo Finance through the `quantmod` R package.

## Reproducibility note

The 15-stock set is a **screened candidate universe**, not a ranking of the 15 best S&P 500 companies. Final portfolio weights are determined later in the project through forecasting, risk estimation, and portfolio optimisation.
